# seoul-parking-hub

서울 주차장 통합 서비스: 주차장 찾기, 실시간 여석, 주차 요금 계산.

## 데이터
| 데이터 | 출처 | 갱신 | 용도 |
|---|---|---|---|
| 서울시 시영주차장 실시간 주차대수 정보 | [서울 열린데이터광장 OA-21709](https://data.seoul.go.kr/dataList/OA-21709/S/1/datasetView.do) | 실시간(5분 이상 지연 가능) | 실시간 여석 (122곳) |
| 전국주차장정보표준데이터 | [공공데이터포털 15012896](https://www.data.go.kr/data/15012896/standard.do) | 반기 | 위치, 운영시간, 요금 |

## 시작하기
1. `.env.example`을 `.env`로 복사하고 인증키를 넣는다. (`.env`는 git에 올라가지 않는다)
